## 🎪 State Transitions Flow

```
USER INTERACTION FLOW

  Idle (🙂)
     │
     │ [User taps/clicks]
     ▼
  Listening (🎧)
     │ [Voice waveform appears]
     │ [User speaks]
     ▼
  Processing (🤔)
     │ [Shimmer effect]
     │ [Analyzing speech]
     ▼
  Speaking (💬)
     │ [AI responds with TTS]
     │ [Ripples with audio]
     ▼
  Success (✨) ─────┐
     │             │
     │ [Complete] │
     ▼             ▼
  Idle (🙂) <──────┘

  
ERROR PATH:
  Any State
     │ [Error occurs]
     ▼
  Error (⚠️)
     │ [Shake animation]
     │ [Show error message]
     ▼
  Idle (🙂)
```
