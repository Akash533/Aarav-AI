# Aarav AI - Mobile Assistant App

A modern, multi-screen mobile application UI/UX design for Aarav AI voice assistant, inspired by the Ello AI Assistant design principles.

## Features

### 🏠 Home Dashboard
- Personalized greeting based on time of day
- Quick stats showing tasks and completion
- AI-powered suggestions
- Quick action buttons for main features
- Recent activity feed

### 📋 Task Management
- Create, view, and complete tasks
- AI-powered task suggestions
- Priority levels (High, Medium, Low)
- Filter tasks by status
- Due date and time tracking

### ✍️ Content Generation
- Generate various types of content (Email, Article, Ideas, Social Posts)
- Customizable tone and length
- Real-time AI content generation
- Copy and share generated content

### 💬 Chat & AI Interaction
- Natural conversational interface
- Real-time AI responses
- Quick suggestion chips
- Voice input support (placeholder)
- Message history

### ⚙️ Settings & Profile
- User profile management
- Appearance settings
- Voice settings
- Privacy & security controls
- Notification preferences

## Design Principles

Following the Ello AI Assistant design approach:

- **Soft Gradients**: Beautiful gradient backgrounds and elements
- **Rounded Shapes**: Smooth, friendly UI components
- **Minimalist Layout**: Clean, focused user interface
- **Clear Typography**: Easy-to-read fonts and hierarchy
- **Responsive Design**: Works on mobile, tablet, and desktop

## Cross-Platform Support

- ✅ **Android**: Fully responsive mobile experience
- ✅ **iOS**: Native-like interface with iOS gestures
- ✅ **Windows**: Desktop-optimized layout (max-width container)
- ✅ **PWA Support**: Installable as a Progressive Web App

## Technology Stack

- **HTML5**: Semantic, accessible markup
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **Vanilla JavaScript**: No dependencies, pure JS
- **Service Worker**: PWA offline support
- **Web Manifest**: App installation metadata

## File Structure

```
aarav-ai-vercel-ready/
├── mobile-app.html     # Main app HTML with all screens
├── mobile-app.css      # Complete styling with gradients
├── mobile-app.js       # App logic and interactivity
├── manifest.json       # PWA manifest

└── icons/             # App icons
```

## Screens Overview

1. **Splash Screen**: Animated logo and loading state
2. **Home Dashboard**: Main hub with quick access
3. **Tasks**: Full task management interface
4. **Content Generator**: AI-powered content creation
5. **Chat**: Conversational AI interface
6. **Settings**: User preferences and configuration

## Navigation

- Bottom navigation bar for main sections
- Floating action button for chat
- Back buttons for secondary screens
- Smooth transitions between screens

## Usage

Simply open `mobile-app.html` in any modern web browser or deploy to:
- Vercel
- Netlify
- GitHub Pages
- Any static hosting service

## Development

No build process required! Pure HTML, CSS, and JavaScript.

To run locally:
1. Open `mobile-app.html` in a browser
2. Or use a local server: `python -m http.server 8000`
