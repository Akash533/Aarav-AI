   - Test user flows

   - Export assets

## 🎨 The AI Orb - Core Concept

The **AI Orb** is the centerpiece of Aarav AI - a living, breathing sphere that represents the AI's consciousness.

### Key Features:
- **Multi-layered design** - Outer rings, inner core, particles, reflections
- **7+ emotional states** - Calm, happy, focused, alert, thinking, success, error
- **Dynamic animations** - Breathing, pulsing, shimmering, rippling
- **Audio-reactive** - Responds to voice input and TTS output
- **Particle effects** - Ambient particles and emission bursts
- **Morphing emoji** - Changes based on state and emotion

### Visual States:
1. **Idle** 🙂 - Gentle breathing, slow rotation
2. **Listening** 🎧 - Pulsing with audio, waveform visible
3. **Processing** 🤔 - Shimmer effect, particle swirl
4. **Speaking** 💬 - Ripples with TTS output
5. **Alert** ⚡ - Fast pulse, amber color
6. **Success** ✨ - Green wash, particle burst
7. **Error** ⚠️ - Red shift, shake animation

**Detailed specs in [AI_ORB_COMPONENT_SPEC.md](AI_ORB_COMPONENT_SPEC.md)**

## 🎬 Animations

### Core Animations
- **Orb breathing** (3s idle loop)
- **Voice waveform** (1.1s per bar, staggered)
- **Ripple effect** (0.6s on tap)
- **Shimmer** (2s processing loop)
- **Particle emissions** (dynamic)

### Timing
- **Micro**: 100-150ms (hover, highlight)
- **Quick**: 200-250ms (button press)
- **Standard**: 300-350ms (modal, drawer)
- **Deliberate**: 400-500ms (page transition)
- **Slow**: 600-800ms (orb state change)

**All specs in [FIGMA_DESIGN_SPEC.md](FIGMA_DESIGN_SPEC.md)**

## 🔧 Implementation Stack Recommendations

### Web
- **Framework**: React, Vue.js, or Svelte
- **3D/Orb**: Three.js, WebGL, or Canvas API
- **Animations**: Framer Motion, GSAP
- **Styling**: Tailwind CSS with custom theme, or Styled Components

### Mobile Native
- **iOS**: SwiftUI + Core Animation
- **Android**: Jetpack Compose + Lottie

### Desktop
- **Cross-platform**: Electron, Tauri
- **macOS native**: SwiftUI
